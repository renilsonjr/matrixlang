My read: option 1. It is a true glyph wall, it costs nothing in height, and it keeps ｱ ﾃ ﾄ ﾗ — the language's own notation — visible in the cascade, which is the thing that makes this MatrixLang rather than generic rain.

Option 2 decodes perfectly but pays twice: every line roughly doubles in height (15 rows instead of 7, and a 30-row field starts refusing to show whole statements), and construct becomes nine glyphs, so the 32-slot table you designed simply does not appear on screen any more.

The cost of option 1, stated plainly: a reader decoding a source line with the translit table gets the identifiers and strings right and the keywords wrong, because ｱ means construct in one table and a letter in the other. Output remains perfectly decodable either way — and output is the part anyone would actually want to read back.
