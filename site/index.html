MATRIXLANG

The code in The Matrix was never a programming language.

This is the one it pretended to have — invented, written down, and made to run.

Nothing in the film runs

The falling green characters are a visual effect. They have no grammar, no meaning attached to any symbol, and no way to be executed. Nobody could type them into a computer and get an answer back, because there is nothing behind them to answer.

So this project is not "recreate the Matrix language." There is nothing to recreate. It is the other thing:

Invent the language the film pretended to have.

A real one, with rules a program either follows or is rejected for breaking. It stores values, makes decisions, repeats work, defines functions that remember where they were written, and handles numbers, text, true and false, and lists. It is Turing-complete, which is the technical way of saying there is no arbitrary ceiling on what you can express in it. Programs live in files ending in .rain, and there is an interpreter that runs them, an interactive prompt for trying things a line at a time, and a test suite that has to stay green before any of this changes.

When a program runs, its own source and its own output fall through a window as glyphs. Nothing on that screen is generated at random. Every character that falls came from the program you ran.

Two faces

Every program can be written and read two ways. Here is one program, twice:

Neither of those is a translation of the other. The program is read once, into a single structure, and that structure can be printed in either face — which is why the conversion loses nothing and can be run in both directions without drift. Feed the glyphs back in and the text comes out again — spacing normalized to the canonical form, and otherwise the program you started with. Run either face and the same thing happens.

Names you chose and text you quoted stay as you wrote them here, because this is source you are meant to keep editing. The cascade window is stricter: it transliterates everything, so what falls is a wall with no Latin in it, and the table is reversible, so it can be read back rather than merely watched.

The glyphs are ordinary Unicode half-width katakana. They are not the film's own glyph designs, and nothing here uses them.

What it looks like

You do not need to know any of those keywords to get a program out of this. Scribe takes a plain-English request and writes the MatrixLang for it. It is not an AI: it is a fixed catalogue of phrasings it was taught in advance, matched exactly, so the same request always produces the same program — and a request outside the catalogue is refused with the closest phrasing it does know, rather than answered with a guess.

Below is every example on this page: what was asked for, what Scribe wrote, and what that program printed. None of it was typed here by hand. It was produced by running the real interpreter, and a test compares this page against a fresh run, so an example cannot quietly go stale.

construct names a value, trace prints one, dejavu loops, redpill is if, agent defines a function, jackout returns from one, and flatline closes whichever of those you opened. There are fourteen keywords in total.

Now run one yourself

Everything above had already happened before you arrived. What comes next has not.

The button below fetches Python — the real one, compiled to run inside a browser — along with this project's package, and starts the actual interpreter in this tab. Everything you have read so far cost about 100 KB, most of it the typeface this page is set in; this costs roughly 13 MB, fetched once and then cached, and took about three seconds on a fast connection. That is the whole reason it waits for you to ask. After it loads, nothing you type leaves your machine, because there is no server on the other end of it: the language is running on your device, and this page has nowhere to send anything even if it wanted to.

Describe a program and Scribe writes it, needing no account and no key. Edit what it wrote, or ignore it and type MatrixLang directly. Then run it, and watch it fall.
